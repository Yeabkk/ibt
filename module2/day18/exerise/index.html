Exercises

  1. Given an array of ETB prices, use map to add 15% VAT, filter to keep those under 1000, and reduce to a grand total.

  2. Build a customer object with name, city and balance, then log every key and value using Object.entries in a for...of loop.

  3. Destructure name and city from a customer in one line, then write a function greet({ name }) that uses parameter destructuring.

  4. Take a customer object and produce an updated copy with spread that changes the city and adds a phone field — without mutating the original.

  5. Split a tiny program into two files: a money.js module that exports addVat and VAT, and an app.js that imports and uses them.
